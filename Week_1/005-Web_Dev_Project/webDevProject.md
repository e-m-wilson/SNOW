## Project Overview
In this project, you will create a **responsive web application** that displays dynamic content retrieved from an external API. The goal is to apply your knowledge of **HTML, CSS, and JavaScript** while practicing modern techniques such as **Flexbox layout** and the **Fetch API**.  

By the end, you’ll have a fully functioning web app that looks professional and is interactive.

---

## Requirements

### 1. HTML Structure
- Use **semantic HTML** elements (`header`, `main`, `section`, `article`, `footer`).
- Include a **navigation bar** with at least 3 links (they can be placeholders).
- Add a **main content area** where dynamic data will be displayed.
- Provide a **form** with at least:
  - An input field
  - A button

---

### 2. CSS Styling
- Use an **external CSS file** for all styles.
- Apply **Flexbox** for layout:
  - Navigation bar should use flexbox to arrange items.
  - Main content should use flexbox or a grid to display cards/items.
- Define a **consistent color scheme and typography**.
- Add **hover effects** on buttons and links.
- Ensure the app is **responsive**:
  - Works on desktop, tablet, and mobile.
  - Use **media queries** for layout adjustments.

---

### 3. JavaScript Functionality
- Use **Fetch API** to retrieve data from a public API (examples: [JSONPlaceholder](https://jsonplaceholder.typicode.com/), [PokeAPI](https://pokeapi.co/), [OpenWeather](https://openweathermap.org/api), [TMDB API](https://developer.themoviedb.org/reference/intro/getting-started)).
- Dynamically create and insert **cards or list items** into the DOM using the fetched data.
- Add **form functionality**:
  - When the user submits input (e.g., a search term), update the displayed data accordingly.
- Use **event listeners** for interactivity.

---

### 4. Additional Features (Bonus Points)
- Add a **loading indicator** while fetching data.
- Display an **error message** if the API request fails.
- Store **user preferences** (like theme or last search) in **localStorage**.
- Add a **dark mode toggle** (use JavaScript + CSS classes).

---

## Deliverables
- **Project Folder** containing:
  - `index.html`
  - `style.css`
  - `script.js`

---

## Example Project Ideas
1. **Weather Dashboard**: User searches a city → app fetches and displays weather.  
2. **Pokédex**: Display Pokémon cards with images and stats from PokeAPI.  
3. **News Reader**: Fetch headlines from a news API and display them.  
4. **Movie Search App**: Use [TMDB API](https://developer.themoviedb.org/reference/intro/getting-started) to fetch and display movie info.
